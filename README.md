# Encryptor Voice — Telegram-бот для расшифровки голосовых сообщений и кружков

Encryptor Voice — Telegram-бот, который принимает голосовые сообщения и кружки (видео сообщения) и преобразует их в текст. Бот использует pydub для конвертации аудио/видео, библиотеку SpeechRecognition (Google Web Speech API) для распознавания речи и построен на современной модульной архитектуре. Проект распространяется под лицензией Apache 2.0 (см. файл LICENSE).

## Возможности
- ✅ Расшифровка голосовых сообщений из Telegram
- ✅ Расшифровка кружков (видео сообщений) с извлечением аудио
- ✅ Конвертация OGG/MP4 в WAV с помощью FFmpeg
- ✅ Распознавание речи через Google Web Speech API
- ✅ Автоматическое удаление временных файлов после обработки
- ✅ Модульная архитектура с сервисными классами


## Требования
- Python 3.8+
- FFmpeg (должен быть установлен в системе и доступен в PATH)
- Интернет (для доступа к Google Web Speech API)
- Зависимости из `requirements.txt`

Основные Python-библиотеки:
- aiogram — Telegram bot framework
- SpeechRecognition — распознавание речи
- pydub — конвертация аудио
- python-dotenv — загрузка переменных окружения

## Установка

1. Клонируйте репозиторий:
   git clone https://github.com/Kan1es/encryptor_voice.git
   cd encryptor_voice

2. Установите системную зависимость: FFmpeg.
   - На Ubuntu/Debian:
     sudo apt update && sudo apt install ffmpeg
   - На macOS (Homebrew):
     brew install ffmpeg
   - На Windows — скачайте сборку FFmpeg и добавьте в PATH.

3. Установите Python-зависимости:
   python -m pip install -r requirements.txt

4. Создайте файл `.env` в корне проекта и добавьте токен бота:
   BOT_TOKEN=123456:ABC-DEF...

## Быстрый запуск
Запустите бота локально:
python main.py

Бот начнёт polling и будет обрабатывать входящие голосовые сообщения.

## Примеры использования
1. Откройте диалог с ботом в Telegram.
2. Отправьте команду `/start` для получения информации о боте.
3. Отправьте голосовое сообщение или кружок (видео сообщение).
4. Дождитесь ответа бота с расшифровкой текста. В процессе будет показано сообщение о конвертации и распознавании.


## Как это работает

### Архитектура
Бот построен на модульной архитектуре с разделением ответственности:
- **Config** — управление конфигурацией и переменными окружения
- **FileManager** — скачивание и очистка временных файлов
- **AudioProcessor** — конвертация аудио и извлечение аудио из видео
- **TranscriptionService** — распознавание речи через Google API

### Процесс обработки
1. Бот получает голосовое сообщение (OGG) или кружок (MP4)
2. FileManager скачивает файл из Telegram
3. AudioProcessor конвертирует в WAV:
   - Для голосовых: OGG → WAV
   - Для кружков: MP4 → извлечение аудио → WAV
4. TranscriptionService распознает речь (язык по умолчанию: ru-RU)
5. Результат отправляется пользователю
6. Временные файлы автоматически удаляются


## Отладка и распространённые ошибки
- "Не найдена программа FFmpeg" — убедитесь, что FFmpeg установлен и доступен в PATH. На Windows добавьте путь к ffmpeg.exe в переменные окружения.
- BOT_TOKEN не задан — проверьте, что `.env` содержит корректный BOT_TOKEN.
- "Не удалось распознать речь" — качество аудио или фоновые шумы могут мешать распознаванию.
- Ограничения Google Web Speech API: бесплатный метод может иметь ограничения по длительности/частоте запросов и точности.

## Конфиденциальность
Аудиофайлы временно сохраняются на сервере для конвертации и распознавания, затем удаляются (см. main.py). Распознавание выполняется с использованием Google Web Speech API — аудиоданные отправляются в сторонний сервис для обработки. Убедитесь, что вы уведомили пользователей об этом, если обрабатываете конфиденциальные данные.
